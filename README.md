# Hub Control com Supabase

Este projeto utiliza exclusivamente o banco de dados do Supabase como backend, configurado pelas variáveis de ambiente `NEXT_PUBLIC_SUPABASE_URL` e `NEXT_PUBLIC_SUPABASE_ANON_KEY` no arquivo `.env.local`.

Para mais detalhes, consulte o arquivo `README_SUPABASE.md`.

This is a NextJS starter in Firebase Studio.

To get started, take a look at src/app/page.tsx.
