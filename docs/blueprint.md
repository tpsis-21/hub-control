# **App Name**: IPTV Manager Pro

## Core Features:

- Gerenciamento de Clientes: Gerenciamento de clientes: registro abrangente de clientes, incluindo nome, nome de usuário IPTV, senha (opcional), e-mail (opcional), WhatsApp (números nacionais e internacionais), endereço (opcional), CPF/CNPJ (opcional), data de início do serviço, data de expiração, status (Ativo, Em teste, Inativo, Bloqueado), notas internas, tags/categorias personalizáveis e seleção de gateway de pagamento.
- Gerenciamento de Planos: Gerenciamento de Planos: registro de planos com nome, valor, validade (dias, meses), número de telas permitidas e restrições (por exemplo, apenas smart TVs). Gerenciamento de promoções e cupons de desconto. Controle de disponibilidade (para revendedores com estoque limitado).
- Notificações Automatizadas: Notificações automatizadas: Envie notificações automáticas e manuais para mensagens de boas-vindas, criação de teste, lembretes de expiração de teste, datas de vencimento próximas (3, 2, 1 dias antes, no dia, 2, 3, 7 dias depois), avisos de atraso, confirmações de pagamento, renovações, promoções e campanhas via WhatsApp e e-mail, com modelos personalizáveis.
- Notificação de Expiração: Notificação de expiração: Envio diário automatizado de notificação de expiração.
- Recomendações de IA: Recomendações com IA: Utilize IA para sugerir planos ou promoções com base no comportamento do cliente. A ferramenta de IA analisa os dados do usuário para identificar upgrades de plano ideais, descontos personalizados e ofertas especiais, melhorando a satisfação do cliente e impulsionando as vendas.

## Style Guidelines:

- Cor primária: Use um azul calmo (#64B5F6) para evocar confiança e confiabilidade, essencial para gerenciar assinaturas e pagamentos de clientes.
- Cor de fundo: Cinza claro (#F5F5F5), quase branco, para manter uma sensação limpa e profissional, auxiliando na legibilidade e reduzindo a fadiga visual.
- Cor de destaque: Laranja complementar (#FFA726) para ações e destaques importantes, chamando a atenção para elementos-chave e aprimorando a interação do usuário.
- Fonte do corpo e título: 'Inter', uma fonte sans-serif versátil conhecida por sua clareza e estética moderna, será usada para títulos e corpo do texto.
- Ícones nítidos e profissionais que representam claramente cada função (por exemplo, perfis de usuário, faturamento, notificações) para uma navegação intuitiva.
- Layout limpo e organizado que é fácil de navegar tanto no desktop quanto no celular, garantindo uma experiência de usuário perfeita.
